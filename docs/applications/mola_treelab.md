# MOLA TreeLab

[MOLA TreeLab](https://pypi.org/project/mola-treelab/) is a graphical
application for viewing and editing CGNS trees. It uses Noder's node model and
is a useful companion when a visual, interactive view is more convenient than
the terminal browser.

See the [MOLA TreeLab project page](https://pypi.org/project/mola-treelab/)
for installation instructions, releases and usage information.
